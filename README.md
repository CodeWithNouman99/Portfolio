## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/CodeWithNouman99/Portfolio.git
```

Move into the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
